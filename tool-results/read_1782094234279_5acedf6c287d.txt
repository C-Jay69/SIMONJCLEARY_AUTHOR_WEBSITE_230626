   169→
   170→**Inputs** (use shadcn RadioGroups / Select / ToggleGroup):
   171→- Setting: Fells Point · Sparrows Point · The Harbor · Greenmount Ave · The Marshes
   172→- Hour: Dusk · 3 a.m. · First light
   173→- Mood: Rain · Grief · Rage · Stillness
   174→
   175→**Output**: a single passage (60–120 words), first or third person, present or
   176→past tense, atmospheric, sensory (rain, ash, rust, breath), no graphic violence,

   290→## 10. API Contracts (backend agent implements)
   291→
   292→Base path: relative `/api/...`. All responses JSON.
   293→
   294→1. `POST /api/newsletter/subscribe`
   295→   - Body: `{ email: string, name?: string }`
   296→   - 200: `{ ok: true, id: string }` (dedupe on email — if exists, still return ok)
   297→   - 400: `{ ok: false, error: "Invalid email" }`
   298→   - Use zod to validate. Insert into `Subscriber`.
   299→
   300→2. `POST /api/contact`
   301→   - Body: `{ name, email, subject?, message }` (all strings)
   302→   - 200: `{ ok: true, id }`; 400 on validation fail.
   303→   - Insert into `ContactMessage`.
   304→
   305→3. `POST /api/story-lab`
   306→   - Body: `{ setting: string, hour: string, mood: string }` (validate against allowed lists)
   307→   - 200: `{ ok: true, story: string }`
   308→   - Uses `z-ai-web-dev-sdk`:
   309→     ```ts
   310→     import ZAI from 'z-ai-web-dev-sdk';
   311→     const zai = await ZAI.create();
   312→     const response = await zai.chat.completions.create({
   313→       model: 'glm-4.6', // or whatever the default chat model is; use create() default
   314→       messages: [
   315→         { role: 'system', content: SYSTEM_PROMPT },
   316→         { role: 'user', content: `Setting: ${setting}\nHour: ${hour}\nMood: ${mood}\n\nWrite the passage.` }
   317→       ],
   318→       thinking: { type: 'disabled' },
   319→       temperature: 0.9,
   320→       max_tokens: 300,
   321→     });
   322→     ```
   323→   - SYSTEM_PROMPT (exact): 
   324→     "You are Simon J Cleary, a Baltimore noir novelist and author of the Mike Savage detective series (The Long Dark Pier, Ash & Iron, Ghosts in the Ash). Write a single original noir passage of 60–120 words in Simon's voice: literary, clipped, concrete, sensory (rain, ash, rust, breath, wet light), quietly tender, no graphic violence, ending on a haunting image. It may evoke detective Mike Savage or the city of Baltimore but must NOT quote or summarize the actual books. Write fresh prose. No headings, no preamble, no quotation marks around the whole thing, no meta commentary — just the passage."
   325→   - Trim the returned story. If empty, return a graceful fallback passage.
   326→   - NOTE: the SDK must run server-side only. This route must NOT be imported by client code; the client fetches `/api/story-lab` via `fetch`.
   327→
   328→**Reads**: The frontend `page.tsx` (a Server Component) reads directly from Prisma via `import { db } from '@/lib/db'`. NO read API routes needed. The three POST routes above are the only API routes.

   402→### Motifs / atmosphere
   403→- **Film grain overlay**: a fixed, pointer-events-none full-screen layer with an SVG turbulence noise data-URI at low opacity (~0.05 dark / 0.04 light), `mix-blend-mode: overlay` or `soft-light`. Subtle.
   404→- **Vignette**: radial-gradient fixed overlay, darker at edges, very subtle.
   405→- **Ember hairline**: 1px accent rules under section eyebrows.
   406→- **Case-file labels**: monospace uppercase, letter-spaced, muted-foreground, with a leading `//` or `FILE 003 —`. e.g. `// MIKE SAVAGE · BOOK 03`.
   407→- **Redaction bar**: a solid `--ash` block used sparingly in the Case File section to "redact" a word, with the word hidden.
   408→- **Distressed texture**: optional subtle `bg-blend` on the hero only.
   409→- **Subtle motion**: framer-motion fade+blur-up on sections (opacity 0→1, y 16→0, 0.5s ease). Respect `prefers-reduced-motion`.
   410→- **Scroll**: smooth via `scroll-behavior: smooth` + `scroll-margin-top` on sections for the sticky header offset.
   411→
   412→### Layout / structure
