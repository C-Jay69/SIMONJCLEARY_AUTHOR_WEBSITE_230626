   163→   163→
   164→   164→**Concept**: A visitor picks a Baltimore setting, an hour of night, and a mood.
   165→   165→The site generates an original ~100-word noir passage "in the spirit of the Mike
   166→   166→Savage novels." This is the signature AI showcase. Include a clear, tasteful
   167→   167→disclaimer: *"Generated by the Savage Engine — an AI writing experiment in Simon's
   168→   168→voice. Not an actual excerpt from the books."*
   169→   169→
   170→   170→**Inputs** (use shadcn RadioGroups / Select / ToggleGroup):
   171→   171→- Setting: Fells Point · Sparrows Point · The Harbor · Greenmount Ave · The Marshes
   172→   172→- Hour: Dusk · 3 a.m. · First light
   173→   173→- Mood: Rain · Grief · Rage · Stillness
   174→   174→
   175→   175→**Output**: a single passage (60–120 words), first or third person, present or
   176→   176→past tense, atmospheric, sensory (rain, ash, rust, breath), no graphic violence,
   177→   177→ends on a haunting image. Voice: literary noir, clipped, concrete, a little
   178→   178→tender. Must feel like Simon's prose.
   179→   179→
   180→   180→**Backend**: `POST /api/story-lab` body `{ setting, hour, mood }` → `{ story }`.

   290→   290→## 10. API Contracts (backend agent implements)
   291→   291→
   292→   292→Base path: relative `/api/...`. All responses JSON.
   293→   293→
   294→   294→1. `POST /api/newsletter/subscribe`
   295→   295→   - Body: `{ email: string, name?: string }`
   296→   296→   - 200: `{ ok: true, id: string }` (dedupe on email — if exists, still return ok)
   297→   297→   - 400: `{ ok: false, error: "Invalid email" }`
   298→   298→   - Use zod to validate. Insert into `Subscriber`.
   299→   299→
   300→   300→2. `POST /api/contact`
   301→   301→   - Body: `{ name, email, subject?, message }` (all strings)
   302→   302→   - 200: `{ ok: true, id }`; 400 on validation fail.
   303→   303→   - Insert into `ContactMessage`.
   304→   304→
   305→   305→3. `POST /api/story-lab`
   306→   306→   - Body: `{ setting: string, hour: string, mood: string }` (validate against allowed lists)
   307→   307→   - 200: `{ ok: true, story: string }`
   308→   308→   - Uses `z-ai-web-dev-sdk`:
   309→   309→     ```ts
   310→   310→     import ZAI from 'z-ai-web-dev-sdk';
   311→   311→     const zai = await ZAI.create();
   312→   312→     const response = await zai.chat.completions.create({
   313→   313→       model: 'glm-4.6', // or whatever the default chat model is; use create() default
   314→   314→       messages: [
   315→   315→         { role: 'system', content: SYSTEM_PROMPT },
   316→   316→         { role: 'user', content: `Setting: ${setting}\nHour: ${hour}\nMood: ${mood}\n\nWrite the passage.` }
   317→   317→       ],
   318→   318→       thinking: { type: 'disabled' },
   319→   319→       temperature: 0.9,
   320→   320→       max_tokens: 300,
   321→   321→     });
   322→   322→     ```
   323→   323→   - SYSTEM_PROMPT (exact): 
   324→   324→     "You are Simon J Cleary, a Baltimore noir novelist and author of the Mike Savage detective series (The Long Dark Pier, Ash & Iron, Ghosts in the Ash). Write a single original noir passage of 60–120 words in Simon's voice: literary, clipped, concrete, sensory (rain, ash, rust, breath, wet light), quietly tender, no graphic violence, ending on a haunting image. It may evoke detective Mike Savage or the city of Baltimore but must NOT quote or summarize the actual books. Write fresh prose. No headings, no preamble, no quotation marks around the whole thing, no meta commentary — just the passage."
   325→   325→   - Trim the returned story. If empty, return a graceful fallback passage.
   326→   326→   - NOTE: the SDK must run server-side only. This route must NOT be imported by client code; the client fetches `/api/story-lab` via `fetch`.
   327→   327→
   328→   328→**Reads**: The frontend `page.tsx` (a Server Component) reads directly from Prisma via `import { db } from '@/lib/db'`. NO read API routes needed. The three POST routes above are the only API routes.
